# 店小二 (dianxiaoer-skill) 使用指南

欢迎使用店小二跨境电商选品与 1688 供应链核价 Skill（MCP 插件）。本指南专供 WorkBuddy、Codex、Antigravity 等智能 Agent 及其人类宿主使用，旨在说明如何下载、配置及使用该技能进行全自动化的一键选品。

## 1. 傻瓜式一键安装 (推荐)

为方便没有任何技术背景的商家使用，我们提供了全自动一键配置脚本。它会自动为您安装环境依赖，并直接挂载到您正在使用的 AI Agent（支持 Antigravity, Claude Desktop 等）。

**第一步：下载插件包**
您可以直接点击 [下载压缩包] 并解压到一个您常用的文件夹中（或使用 `git clone`）。

**第二步：运行一键安装脚本**
进入解压后的文件夹：
- **Windows 用户**：直接双击运行 `install_win.bat`
- **Mac 用户**：直接双击运行 `install_mac.command`

**第三步：按提示操作**
弹出黑色命令行窗口后，按提示输入您正在使用的 AI 客户端对应的数字（如 1 代表 Antigravity），脚本会自动为您注入配置！

*安装成功后，请完全退出并重启您的 AI 客户端，即可直接在聊天框对话！*

---

## 2. 配置与认证

店小二的选品流水线依赖后端的 `shop-dianxiaoer-svc` 服务。

**授权配置**：
本 Skill 在运行时会自动寻找目录下的 `.dianxiaoer/agent-auth.json` 授权凭证。如果凭证不存在或过期，会在首次调用工具时返回提示，引导宿主先前往线上平台进行“Agent 设备授权登录”并获取鉴权 Token。
*Agent 遇到 401 或授权提示时，请直接将该提示原样转告人类用户即可。*

---

## 3. 如何使用（选品实战）

配置好 MCP 后，Agent 的上下文环境中就会自动加载原生的 `dianxiaoer` MCP 工具（如 `dianxiaoer_run_sourcing_pipeline`）。

### 3.1 核心选品指令
用户随时可以使用自然语言向 Agent 发达选品需求。例如：
- **“帮我选品，关键词是 比基尼”**
- **“帮我挖掘一下家居爆品，只要价格在 10 到 50 美元之间的”**
- **“找 5 款指尖陀螺，要求历史销量大于 100”**

### 3.2 Agent 的处理逻辑（一键自动化）
当 Agent 接收到用户的选品需求后，**无需自己编写代码或脚本**，直接提取用户给定的条件，并调用一条 MCP 工具即可：

**工具名称**：`dianxiaoer_run_sourcing_pipeline`（或通过 `call_mcp_tool` 间接调用）
**参数示例**：
```json
{
  "keyword": "家居爆品",
  "min_sales": 100,
  "price_min": 10.0,
  "price_max": 50.0,
  "max_items": 5
}
```

### 3.3 自动化流水线流转
调用后，系统会在后台全自动执行以下操作，Agent 只需耐心等待返回结果：
1. **Temu 商品抓取**：自动前往 Temu 搜索该关键词下的热销爆款。
2. **多模态匹配**：自动提取商品主图。
3. **1688 寻源核价**：利用图片前往 1688 寻找同款货源。
4. **商家询价与旺旺联络**：自动给 1688 商家发送砍价话术（带商品链接）。
5. **利润表生成**：自动汇总采集到的供货价与零售价，生成双轨财务利润报表与 Excel 导出。

### 3.4 最终呈递
工具调用执行完毕后，Agent 会收到一条详细的 Markdown 格式核价与选品分析报告，Agent 应将报告的核心利润数据、高潜商品、Excel 下载链接等关键信息总结后，直接呈递给人类用户。

> **⚠️ 严禁造假红线**：
> 作为 Agent，请务必真实呈递 MCP 工具返回的数据结果。**绝对严禁**通过硬编码或 AI 幻觉编造虚假的 1688 供货价或商家回复来糊弄用户！如果遇到风控或超时，请如实向用户反馈异常。
